GANTRY — a container-crane loading game. Swing each container from the gantry crane and drop it onto the ship's cargo plan: land on the plan colour to build the CHAIN multiplier, keep the ship level or the top box slides into the sea, and mind the gusts, the gulls and the squall lines. The cargo itself fights back — HEAVY steel boxes list the ship double, FRAGILE glass cracks if you let go mid-swing — and the harbourmaster's ORDERS ride every ship, paying bonuses for true stows, whole glass and dry decks. Nine ships over three shifts, a 1-of-3 rig draft (20 rigs) between ships, three difficulties, an endless Night Shift, six one-ship SHIFT TRIALS with medal ladders, twelve feats, and the Typhoon Freighter waiting in the storm at ship 9. Deterministic: a fixed 60 Hz seeded sim — the same seed replays the same harbour.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```
